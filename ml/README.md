# ML Pipeline

This directory contains ML pipeline scripts for AlgoTrade Sentinel.

## Planned Modules (Phase 2+)

- `data/` — Feature engineering and dataset preparation
- `models/` — Model definitions (LSTM, XGBoost, ensemble)
- `train.py` — Training pipeline entry point
- `evaluate.py` — Model evaluation and metrics
- `predict.py` — Inference pipeline

## Stack

- scikit-learn, XGBoost, LightGBM
- PyTorch (LSTM/Transformer models)
- MLflow (experiment tracking)
- Optuna (hyperparameter optimization)
- Prefect (pipeline orchestration)
